# Offshore Creative Fashion

Editable static landing page. The homepage, stylesheet, JavaScript and assets are at the repository root. No package installation or build step is required.

## Run locally

Extract the ZIP. From the folder containing index.html, run `python3 -m http.server 8000` and open http://localhost:8000.

## Edit

Edit index.html for copy, gallery items and GitHub-hosted film URLs. Edit style.css for layout and fashion.js for viewport autoplay, the portfolio viewer and WhatsApp inquiries. Keep images, posters and fonts in assets/. The five films stream from GitHub and require an internet connection.

## Deploy

Upload the extracted contents to your GitHub repository with index.html at its root. For GitHub Pages, select branch publishing and the root folder. For Vercel, import the repository as a static project, choose Other, skip the build command and serve the repository root.
