# Offshore Creative Fashion
Extract this ZIP and run `python3 -m http.server 8000` in the folder containing index.html. Open http://localhost:8000. No dependencies or build step are required.

Edit index.html for copy, hero photos, gallery items and film URLs. style.css controls the layout. fashion.js controls the slideshow, autoplay previews, film viewer and WhatsApp form. Keep assets/ beside index.html. Videos stream from GitHub and require internet access.

For GitHub Pages, upload the extracted files to the repository root and publish that folder from your deployment branch. For Vercel, import the repository as a static project using the Other preset, no build command, and the repository root as the output directory.
