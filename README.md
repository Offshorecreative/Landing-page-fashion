# Offshore Creative Fashion
Extract all files into one folder. Run `python3 -m http.server 8000` in that folder and visit http://localhost:8000. No dependency installation or build is needed.

Edit index.html for content, image paths, and video URLs. Edit style.css for appearance and fashion.js for interactions. Keep assets/ alongside index.html. The hero and five portfolio films stream from GitHub and require internet access.

For GitHub Pages, upload the extracted contents to the repository root and publish the root folder of your branch. For Vercel, import the repository, select the Other preset, leave the build command empty and serve the repository root.
